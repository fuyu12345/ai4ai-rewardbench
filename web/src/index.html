Each pair contributes equally. The model predicts A, B, or tie against a frozen label, following the task-specific decision rule.

What do these results establish?+

A snapshot of preference judgment on a curated development collection. These are historical labels, not an independently sampled hidden test set. They do not establish a general model ranking.

How are the two modes evaluated?+

Reasoning receives all public materials inline. Agent uses read-only tools constrained to the public manifest. Neither mode receives organizer labels. Runs use fixed A/B order and provider-default sampling; no position-swap study is claimed.

What counts as resource use?+

Reported input/output tokens include failures, repairs and recovery attempts. Cached input is a subset of input. Agent model turns, tool rounds, tool calls and API attempts are distinct; missing usage is not zero.

What are the known limitations?+

Labels are imbalanced. Two source-code cases retain performance self-reports. Recovery budgets differ, including extended hy4 retries. Gemini signature compatibility handling and answer parsing repairs are documented. The single Claude refusal is excluded only under the stated avg@2 exception.
